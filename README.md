# Personal Finance Forecaster

A Python-based financial modeling engine that parses bank statements (CSV) to visualize spending habits and calculate mortgage/loan eligibility.

## Features

- **Categorization Engine:** Automatically tags expenses as "Fixed" (Needs) or "Variable" (Wants).
- **Affordability Algorithm:** Calculates your **Debt-to-Income (DTI)** ratio to simulate bank loan approval logic.
- **Privacy First:** Data is processed locally; no bank data is stored.
- **Educational Dashboard:** Explains financial concepts (DTI, Cash Flow) in plain English.
